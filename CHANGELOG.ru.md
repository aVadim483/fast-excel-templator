## [Unreleased]

### Исправлено
- `insertRow()` использует копию образца: частичные данные не наследуют значения предыдущей вставки. Выбор образцов из коллекции независим от `foreach`.
- `transferRows(0)` и `skipRows(0)` не меняют курсоры; отрицательные количества и границы вызывают исключение. Обработка до границы разреженного листа не поглощает следующую существующую строку.
- Отсутствующие строки диапазона образцов возвращаются как пустые образцы; пустая XML-строка не забирает ячейки следующей строки. Недопустимые диапазоны и пустая коллекция дают явное исключение.
- Метаданные листа сохраняются отдельным потоковым проходом: условное форматирование, все атрибуты и узлы проверок данных, гиперссылки, таблицы, привязки изображений и примечаний, виды листов и расширения. Исправлена загрузка `dxfs`; сохраняются палитры, стили таблиц и расширения стилей.
- Потоковый путь новых версий Reader теперь перебазирует формулы при перемещении ячеек. Горизонтальные объединения сужаются при удалении ячеек внутри них; сдвиг, затрагивающий объединение из нескольких строк, отклоняется.
- `setValue(..., null)` очищает содержимое и старую формулу с сохранением оформления. Исправлено чтение XML-флагов и экранированного текста колонтитулов.
- Данные листов сохраняются в соответствующие исходные XML-части даже при несовпадении порядка листов книги и номеров файлов внутри ZIP.

### Добавлено
- Опция `strict_metadata` и `metadataDiagnostics()`: неподдерживаемые изменения диапазонов и неизвестные элементы отражаются в диагностике; строгий режим отклоняет сохранение до размещения результата.
- Матрица поддержки XLSX на двух языках и эталоны, созданные Excel и LibreOffice.
- CI на Windows и Ubuntu с PHP 7.4, 8.0–8.5, отдельные проверки минимальных зависимостей на PHP 7.4; PHPStan уровня 1 без baseline и подавлений (`composer analyse`).

### Тесты
- Добавлены проверки метаданных, ZIP relationships, изображений, примечаний, файловых ссылок, очистки через null, разреженных строк, объединений и офисных эталонов.
- Тесты символических ссылок используют нативные разделители Windows и проверяют доступность цели до сохранения. Проверка оборванной ссылки создаёт существующую цель и удаляет её после создания ссылки, чтобы выполняться и на Windows.

### Документация
- README и справочник API дополнены примерами независимых вставок, правилами курсоров и очистки ячеек. Матрица поддержки содержит коды диагностики, обработку строгого отказа и ограничения структурных операций.

### Совместимость
- Код, рассчитывавший на изменение образца при вставке или на общий курсор вставок и `next()`/`foreach`, должен задавать значения и выбирать образцы явно. Поведение публичного `next()` сохранено; добавлен независимый `nextTemplate()`.
- Диапазоны метаданных и привязки рисунков при структурных изменениях сохраняют координаты шаблона. Строгий режим консервативно отклоняет такие операции; правила описаны в XLSX_SUPPORT.ru.md.

## [3.3.1] - 2026-10-08

### Исправлено
- Сохранение собирает книгу во временном файле в каталоге назначения и размещает только готовый результат. При ошибке генерации или размещения прежний результат сохраняется; перезапись исходного шаблона запрещена.
- `save(..., false)` соблюдает запрет перезаписи, в том числе если целевой файл появился во время генерации.
- Замена содержимого архива проверяет открытие ZIP, запись элементов и закрытие; ресурсы освобождаются при исключениях. Для поддерживаемых версий зависимости эти проверки обеспечивает локальный адаптер Writer.
- Writer шаблонизатора больше не сохраняет книгу при уничтожении объекта; при ошибке скачивания временные файлы очищаются.
- `RowTemplate::setValue()` удаляет прежнюю формулу и сбрасывает метаданные исходного типа при присваивании нового значения, сохраняя стили.
- При удалении ячеек стили и объединённые диапазоны перемещаются по тому же целевому адресу, что и значение.

### Тесты
- Добавлены регрессионные проверки безопасного сохранения, ошибок ZIP, очистки при скачивании, замены формул и переноса стилей/объединений после удаления ячеек.

## [3.3.0] - 2026-08-29

### Исправлено
- Два дефекта `avadim/fast-excel-writer`, доходившие до этого пакета, исправлены в writer 6.16.1:
  - ссылка, уехавшая за пределы листа, сохраняла внутреннюю запись RC (`R[-4]C[-1]`) вместо `#REF!`, а диапазон мог получиться наполовину в RC, наполовину в A1 (`SUM(R[-4]C[-1]:A2)`). Шаблоны строк хранят формулы в RC, чтобы перебазировать их при вставке, — так что это задевало любой шаблон, вставленный выше своей исходной строки;
  - книга перенимала локаль другой книги, живущей одновременно с ней (книга с `ru` писала знак евро), потому что менеджер стилей держал статический экземпляр, перезаписываемый каждым конструктором. До темплатора это доходило через `RowTemplate::setCellStyle()` / `setRowStyle()`.
- `Excel::download()` отдавал файл под MIME-типом старого `.xls` (`application/vnd.ms-excel`) вместо типа XLSX и не сообщал `Content-Length`. Кроме того, заголовки уходили даже в уже начатый ответ, дописывая книгу к тому, что было напечатано раньше; теперь об этом сообщается исключением.
- `SheetTemplate::readRow()` завершал цикл по любому falsy-ключу генератора, а не по концу генератора — номера строк начинаются с 1, так что это работало по счастливой случайности.
- Загрузка `styles.xml`, в котором есть `<xf>` вне известных секций, приводила к `TypeError` вместо того, чтобы просто пропустить такой элемент.

### Добавлено
- `Excel::MIME_TYPE` и точки расширения `downloadHeaders()` / `sendHeaders()` / `headersSent()` за `download()`: наследник может изменить отправляемое, а тест — это проверить.

### Изменено
- Поднято требование: `avadim/fast-excel-writer` до `^6.16.1`.

### Тесты
- Тест, который ждал исправления в writer (ссылка за пределами листа должна становиться `#REF!`), больше не пропускается; рядом появился такой же тест для диапазона.
- Две книги с разными локалями, живущие одновременно, проверяются на то, что каждая сохраняет свою валюту.
- Появилось покрытие для `download()` / `output()`, `SheetTemplate::replaceRow()`, `cloneRow()`, `writeRow()`, `writeCell()`, `RowTemplate::removeCell()` / `removeCells()` и книг из нескольких листов.
- Файлы, которые пишет тестовый набор, больше не коммитятся, а игнорируются git.

## [3.2.0] - 2026-08-16

### Исправлено
- Формулы разбираются собственным лексером вместо токенизатора PHP. Токенизатор читал формулы Excel по правилам PHP: `#` начинал комментарий, поэтому ссылки после константы ошибки (`=SUM(#REF!)+A3`) не перебазировались; диапазон распадался на две половины — отсюда смешанная запись вида `R[-4]C[-1]:A2` в сохранённом файле; а `$A$1` читался как переменная. Теперь диапазон конвертируется целиком, а имена листов, строковые литералы, ссылки на таблицы и числа вроде `1E3` отличаются от настоящих ссылок.
- Строка обрывалась, если в одной из ячеек лежало falsy-значение: `RowTemplate` проверял текущее значение вместо ключа, поэтому обход останавливался на середине строки и все последующие ячейки молча терялись.
- В сохранённой книге оставалась висячая ссылка на удалённый `calcChain.xml` — имя части было написано с ошибкой (`workbook.xml.res` вместо `.rels`).
- `Excel::outputFile()` бросал `Error`, если `template()` вызвали без имени выходного файла.
- Ячейка с датой записывалась дважды, второй раз — без числового формата; ячейка, собранная вручную без ключа `t`, вызывала warning.
- `SheetTemplate::mergedRange()` больше не подменяет смысл унаследованного метода: он отвечал только для левой верхней ячейки объединения и возвращал относительные смещения вместо диапазона адресов. Смещения — внутренняя механика, теперь у неё отдельный метод.
- `RowTemplateCollection` объявляет `Iterator`, но обойти его было нельзя: `next()` намеренно циклический, поэтому `foreach` не завершался. Кроме того, коллекция требовала отдельного вызова `setSheet()` перед `cloneCell()`, иначе падала на неинициализированном свойстве; теперь лист можно передать в конструктор.
- `Excel::template()` возвращал `new self`, отдавая наследникам объект `Excel`; теперь возвращает `new static`.
- `Reader::validate()` печатал список файлов с тегами `<br>` вместо того, чтобы его возвращать, и падал при вызове до открытия документа.
- `SheetWriter::getSheetViews()` менял состояние объекта прямо во время ответа; преобразование перенесено на вход данных.
- Ошибки больше не проглатываются: перенос `<dataValidations>` ловит собственное исключение писателя, а не любой `\Throwable`, а `save()` сообщает о файле, который не удалось перезаписать, вместо молчаливого продолжения.

### Изменено
- Подняты требования: `avadim/fast-excel-reader` до `^4.4`, `avadim/fast-excel-writer` до `^6.16`.
- Убрано явное требование `avadim/fast-excel-helper` — он приходит через ридер и писатель, каждый из которых требует `^1.4`.
- Ошибки диапазона строк сообщаются пакетным `Exception` вместо голого `\RuntimeException` (он наследует `RuntimeException`, поэтому существующие `catch` продолжают работать).
- `SheetTemplate::replaceRow()` и `cloneRow()` возвращают `$this`, как остальной fluent-интерфейс.

### Устарело
- `Excel::$instance` — присваивается, но нигде не читается, и перезаписывается каждой новой книгой. Храните объект, который вернул `template()`. Будет удалено в 4.0.

### Производительность
- Захват шаблонной строки больше не перебирает все объединения листа для каждой её ячейки.

### Документация
- Добавлен `BACKLOG.md` с известными нерешёнными задачами, включая два бага `fast-excel-writer`, которые задевают этот пакет.
- Перегенерирован справочник API (в нём не хватало методов ридера 4.4).

## [3.1.0] - 2026-07-25

### Изменено
- Поднято требование `avadim/fast-excel-reader` до `^4.1`: встроенные форматы дат теперь рендерятся детерминированно, независимо от локали среды и от наличия `ext-intl` (см. reader #53).

## [3.0.1] - 2026-07-25

### Исправлено
- Терялся `autoFilter` из шаблона, а его диапазон хардкодился в `A1`: первый узел листа после `</sheetData>` пропускался, поэтому `<autoFilter>` (он идёт первым) не переносился вовсе. Теперь исходный диапазон фильтра из шаблона сохраняется (#21).
- Проверки данных (например, выпадающие списки) не переносились в результат. Теперь `<dataValidations>` переносятся из шаблона (#2).

## [3.0.0] - 2026-07-25

### Ломающие изменения
- Требуется новый мажор базового ридера: `avadim/fast-excel-reader` `^4.0` (ранее `^3`). При обновлении обновите зависимости.

### Изменено
- Поднята зависимость `avadim/fast-excel-writer` до `^6.15`.
- `SheetTemplate::getRowTemplates()` теперь проверяет запрошенный диапазон строк по `<dimension>` листа и бросает `RuntimeException` для строк вне диапазона.

### Производительность
- Объединённые ячейки читаются лениво — при открытии больше не сканируется весь лист для листов, которые не переносятся.
- Исходный DOM-узел удерживается только для ячеек с ошибками, а не для каждой ячейки.

### Документация
- Переработан README (EN + RU): добавлены «Какая библиотека мне нужна?», «Как это работает», «Ограничения» и FAQ;
  задокументированы несколько листов, отдача в браузер (`download()`/`output()`), диапазоны образцов строк
  и различие `fill()` vs `replace()`; исправлены пример `replace()` и имя метода `rows()`.
- Обогащён PHPDoc и перегенерирован справочник API; добавлена страница `RowTemplateCollection`.
- Добавлены этот CHANGELOG (EN + RU) и CI на GitHub Actions (PHP 7.4–8.4).
