## [3.2.0] - 2026-08-16

### Исправлено
- Формулы разбираются собственным лексером вместо токенизатора PHP. Токенизатор читал формулы Excel по правилам PHP: `#` начинал комментарий, поэтому ссылки после константы ошибки (`=SUM(#REF!)+A3`) не перебазировались; диапазон распадался на две половины — отсюда смешанная запись вида `R[-4]C[-1]:A2` в сохранённом файле; а `$A$1` читался как переменная. Теперь диапазон конвертируется целиком, а имена листов, строковые литералы, ссылки на таблицы и числа вроде `1E3` отличаются от настоящих ссылок.
- Строка обрывалась, если в одной из ячеек лежало falsy-значение: `RowTemplate` проверял текущее значение вместо ключа, поэтому обход останавливался на середине строки и все последующие ячейки молча терялись.
- В сохранённой книге оставалась висячая ссылка на удалённый `calcChain.xml` — имя части было написано с ошибкой (`workbook.xml.res` вместо `.rels`).
- `Excel::outputFile()` бросал `Error`, если `template()` вызвали без имени выходного файла.
- Ячейка с датой записывалась дважды, второй раз — без числового формата; ячейка, собранная вручную без ключа `t`, вызывала warning.
- `SheetTemplate::mergedRange()` больше не подменяет смысл унаследованного метода: он отвечал только для левой верхней ячейки объединения и возвращал относительные смещения вместо диапазона адресов. Смещения — внутренняя механика, теперь у неё отдельный метод.
- `RowTemplateCollection` объявляет `Iterator`, но обойти его было нельзя: `next()` намеренно циклический, поэтому `foreach` не завершался. Кроме того, коллекция требовала отдельного вызова `setSheet()` перед `cloneCell()`, иначе падала на неинициализированном свойстве; теперь лист можно передать в конструктор.
- `Excel::template()` возвращал `new self`, отдавая наследникам объект `Excel`; теперь возвращает `new static`.
- `Reader::validate()` печатал список файлов с тегами `<br>` вместо того, чтобы его возвращать, и падал при вызове до открытия документа.
- `SheetWriter::getSheetViews()` менял состояние объекта прямо во время ответа; преобразование перенесено на вход данных.
- Ошибки больше не проглатываются: перенос `<dataValidations>` ловит собственное исключение писателя, а не любой `\Throwable`, а `save()` сообщает о файле, который не удалось перезаписать, вместо молчаливого продолжения.

### Изменено
- Подняты требования: `avadim/fast-excel-reader` до `^4.4`, `avadim/fast-excel-writer` до `^6.16`.
- Убрано явное требование `avadim/fast-excel-helper` — он приходит через ридер и писатель, каждый из которых требует `^1.4`.
- Ошибки диапазона строк сообщаются пакетным `Exception` вместо голого `\RuntimeException` (он наследует `RuntimeException`, поэтому существующие `catch` продолжают работать).
- `SheetTemplate::replaceRow()` и `cloneRow()` возвращают `$this`, как остальной fluent-интерфейс.

### Устарело
- `Excel::$instance` — присваивается, но нигде не читается, и перезаписывается каждой новой книгой. Храните объект, который вернул `template()`. Будет удалено в 4.0.

### Производительность
- Захват шаблонной строки больше не перебирает все объединения листа для каждой её ячейки.

### Документация
- Добавлен `BACKLOG.md` с известными нерешёнными задачами, включая два бага `fast-excel-writer`, которые задевают этот пакет.
- Перегенерирован справочник API (в нём не хватало методов ридера 4.4).

## [3.1.0] - 2026-07-25

### Изменено
- Поднято требование `avadim/fast-excel-reader` до `^4.1`: встроенные форматы дат теперь рендерятся детерминированно, независимо от локали среды и от наличия `ext-intl` (см. reader #53).

## [3.0.1] - 2026-07-25

### Исправлено
- Терялся `autoFilter` из шаблона, а его диапазон хардкодился в `A1`: первый узел листа после `</sheetData>` пропускался, поэтому `<autoFilter>` (он идёт первым) не переносился вовсе. Теперь исходный диапазон фильтра из шаблона сохраняется (#21).
- Проверки данных (например, выпадающие списки) не переносились в результат. Теперь `<dataValidations>` переносятся из шаблона (#2).

## [3.0.0] - 2026-07-25

### Ломающие изменения
- Требуется новый мажор базового ридера: `avadim/fast-excel-reader` `^4.0` (ранее `^3`). При обновлении обновите зависимости.

### Изменено
- Поднята зависимость `avadim/fast-excel-writer` до `^6.15`.
- `SheetTemplate::getRowTemplates()` теперь проверяет запрошенный диапазон строк по `<dimension>` листа и бросает `RuntimeException` для строк вне диапазона.

### Производительность
- Объединённые ячейки читаются лениво — при открытии больше не сканируется весь лист для листов, которые не переносятся.
- Исходный DOM-узел удерживается только для ячеек с ошибками, а не для каждой ячейки.

### Документация
- Переработан README (EN + RU): добавлены «Какая библиотека мне нужна?», «Как это работает», «Ограничения» и FAQ;
  задокументированы несколько листов, отдача в браузер (`download()`/`output()`), диапазоны образцов строк
  и различие `fill()` vs `replace()`; исправлены пример `replace()` и имя метода `rows()`.
- Обогащён PHPDoc и перегенерирован справочник API; добавлена страница `RowTemplateCollection`.
- Добавлены этот CHANGELOG (EN + RU) и CI на GitHub Actions (PHP 7.4–8.4).
